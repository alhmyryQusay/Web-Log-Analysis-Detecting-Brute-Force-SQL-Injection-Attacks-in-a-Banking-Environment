# Web Log Analysis: Detecting Brute Force & SQL Injection Attacks in a Banking Environment

## Project Overview
As part of a **simulated incident** on **TryHackMe**, I analyzed an Apache access log file provided by the security team for a banking environment.  
The team suspected unauthorized activity targeting the bank’s web application.  
My task was to investigate the log entries, identify any malicious patterns, and determine whether the attacker successfully accessed the system.

## Key Highlights
- Investigated web server logs for suspicious activity.  
- Detected potential **Brute Force** and **SQL Injection** attacks.  
- Analyzed log patterns to identify malicious behavior.  
- Determined the success or failure of the attack on the system.  

## Tools & Data Sources
- **Wireshark**  
- **Apache Access Logs**
